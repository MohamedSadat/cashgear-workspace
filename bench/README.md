# Benchmarks and harnesses

Phase 0's spikes (S1 to S9) left these harnesses. Their results are in `docs/DECISIONS.md`
(2026-11-11: Phase 0 results). Since Phase 1 they run on the product's packages: the chosen
schema, the block-id plugin and the binding (with the Q18 patch) come from `@cgw/doc` and the
editor from `@cgw/editor`, so every run tests what ships. Only S1's rejected configurations
(`body* block*`, one node type per kind, upstream `y-prosemirror`) and S2's newer builds are
assembled in `editor/src`. Phase 0's runs of the unpatched fork stay in `DECISIONS.md`; with the
patch installed that is the same code. `results/` is what a run writes; it is not committed, and
CI uploads it as an artifact.
